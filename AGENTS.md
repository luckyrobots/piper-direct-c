# Agent instructions

These rules apply to every coding agent working in this repository (Codex, Claude Code, and others).

## Architecture

Always build code cleanly, modularly, and with proper architecture and separation of concerns. Never simply bolt on a feature because it was asked for. If you can't find an easy way to build it naturally, and you'd recommend a refactor to make the whole thing cleanly, stop your work ahead of time and say so.

See `docs/target-architecture.md` for the target design and the state-machine spec that changes should move toward.
